Do You Need the GitHub Code?

YES — the GitHub code is essential for the developer.

The HTML prototypes on GitHub are the functional specification of the app. They show every screen, every user flow, every text, every piece of business logic (pricing tiers, tip percentages, cancellation policies, partner categories, restaurant data, etc.).

How to use it:
• GitHub → understand what the app does and how it flows
• Figma (from designer) → understand what the app looks like
• When in conflict: Figma wins on appearance, GitHub wins on functionality

Do NOT copy the HTML/CSS directly. Build in React/Next.js referencing GitHub for logic and Figma for design.
