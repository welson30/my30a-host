The product vision

"This is 30A. You should be living it — not managing it."

My30A Host is not a booking engine or a chatbot. It is an AI-powered concierge that delivers the full 30A experience — before guests arrive and throughout their stay. Vitoria handles every question, coordinates every service, and connects guests with the best local partners on the 30A corridor (Rosemary Beach, Alys Beach, WaterColor, Seaside, Watersound, and more).

For guests
Fridge stocked on arrival, ride from the airport, bonfire permits, fishing charters, restaurant reservations — all via chat with Vitoria.
For hosts
Zero guest texts at 10pm. Vitoria handles everything automatically. Hosts pay $99–199/month for their property to offer a 5-star concierge experience.
For partners
Local businesses get direct referrals from guests who came here to live 30A fully. No commission — My30A Host connects, they deliver.

Supabase database schema

Create these tables in Supabase → SQL Editor. Run in order.

-- 1. GUESTS
CREATE TABLE guests (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  language TEXT DEFAULT 'en',
  preferences JSONB DEFAULT '{}', -- dietary, family, favorites
  loyalty_level TEXT DEFAULT 'guest', -- guest | returning | vip
  total_stays INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. ORDERS
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  guest_email TEXT REFERENCES guests(email),
  type TEXT NOT NULL, -- grocery | transfer | welcome | reservation
  status TEXT DEFAULT 'pending', -- pending | confirmed | shopping | on_the_way | delivered
  service_fee NUMERIC,
  items_total NUMERIC, -- actual Publix receipt
  total_paid NUMERIC,
  stripe_session_id TEXT,
  details JSONB, -- order-specific data (items, airport, etc.)
  delivery_date DATE,
  arrival_airport TEXT, -- ECP | VPS | PNS
  arrival_date DATE,
  tip_amount NUMERIC DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. HOSTS
CREATE TABLE hosts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  plan TEXT DEFAULT 'free', -- free | starter | growth | portfolio
  stripe_customer_id TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. PROPERTIES
CREATE TABLE properties (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  host_id UUID REFERENCES hosts(id),
  name TEXT NOT NULL,
  wifi_name TEXT, wifi_pass TEXT,
  checkin_time TIME, checkout_time TIME,
  access_instructions TEXT,
  house_rules TEXT,
  curated_picks JSONB DEFAULT '[]',
  early_access BOOLEAN DEFAULT FALSE,
  services_active BOOLEAN DEFAULT TRUE,
  type TEXT DEFAULT 'house' -- house | hotel
);

-- 5. PARTNERS
CREATE TABLE partners (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL, category TEXT,
  phone TEXT, email TEXT, website TEXT,
  mode TEXT DEFAULT 'soon', -- ref | dir | soon
  commission_pct NUMERIC,
  discount_code TEXT DEFAULT 'MY30A',
  discount_offer TEXT,
  active BOOLEAN DEFAULT FALSE,
  notes TEXT
);

Build order — 4 sprints

🟢 Sprint 1 — Foundation (Week 1) · Must do before any client

  • Connect Supabase — create tables using schema above, add env vars to Netlify
  • Connect Resend — create account at resend.com, add RESEND_API_KEY, verify notify-order.js sends email
  • Configure Stripe webhook — add endpoint in Stripe dashboard → stripe-webhook.js handles events
  • Connect domain my30ahost.com → Vercel (DNS settings at registrar)
  • Test full flow: guest opens app → chats → Vitoria responds → profile saves to Supabase

🔵 Sprint 2 — Order flow (Week 2) · Core revenue

  • Grocery: wire upload button → Netlify Function → Claude Vision reads screenshot → calculates tier → creates Stripe session → sends link to guest
  • Transfer: wire request form → saves to Supabase orders → appears in calendar.html
  • Welcome: same as transfer flow
  • Order status: Welson updates status in calendar → Resend sends automatic message to guest at each stage
  • Stripe card hold: use capture_method:'manual' for transfers and grocery — capture when Welson confirms
  • Tip: Stripe PaymentIntent after order marked delivered

🟡 Sprint 3 — Host SaaS (Week 3)

  • Host signup → Stripe subscription → webhook activates account in Supabase
  • Property setup form → saves to properties table → Vitoria reads on guest app load
  • Host dashboard: pull real data from Supabase (chats count, orders, guest history)
  • QR code generation per property → links to app.html?p={property_id}
  • Loyalty logic: total_stays counter → loyalty_level updates automatically
  • Post-checkout rating: Netlify cron job checks daily for completed orders → Resend sends rating request

🔴 Sprint 4 — AI Agents (Week 4)

  • Pre-arrival transfer agent: daily cron at 9am → query guests arriving in 3 days without transfer → Resend sends proactive offer with Stripe link
  • Grocery OCR agent: Claude Vision processes cart screenshot → auto Stripe link (already designed in Sprint 2 — just the proactive trigger)
  • Partner follow-up agent: 2h after partner email sent → check if order confirmed → if not, send second email → 4h → alert Welson via email
  • Weekly commission reconciliation: every Monday 9am → cron sends email to each active referral partner summarizing MY30A leads from past week
  • Admin toggles: connect rush_order_active and holiday_surcharge_active from admin.html to Supabase config table → app reads dynamically

5 AI agents to build

✈️
Pre-arrival transfer agent
Netlify Scheduled Function — runs daily at 9am. Queries Supabase for guests arriving in 3 days with no confirmed transfer. Sends email via Resend with Stripe payment link (ECP $150 / VPS $225 / PNS $299 pre-filled). No Claude API needed — just email template + Stripe link.
Cost: $0/month (Netlify cron + Resend free tier)
🛒
Grocery OCR agent
Guest uploads Publix cart screenshot → Netlify Function sends image to Claude Vision API with prompt: "List every item with price. Return JSON." → counts items → determines tier (≤30=$175, 31-70=$229, 71-120=$299, 121-200=$379, per $1,000 block above that) → creates Stripe session → sends link to guest. Receipt OCR after delivery → Stripe adjusts difference.
Cost: ~$0.03 per image. 50 orders/month = $1.50
🔔
Partner follow-up agent
When guest makes a partner request, system sends email to partner via Resend. Netlify cron checks every 2h: if partner hasn't confirmed → sends second email. After 4h → sends alert to dealsconnectllc@gmail.com: "Partner X hasn't responded to referral for guest Y." Protects guest experience without manual monitoring.
Cost: $0 (Netlify cron + Resend)
⭐
Post-checkout rating agent
Daily Netlify cron at 11am. Queries orders with status=delivered where checkout_date = today or yesterday. Sends Resend email/message: "How was everything? ⭐⭐⭐⭐⭐" with rating link. Response saved to orders table. Feeds host dashboard satisfaction score and landing page testimonials.
Cost: $0 (Netlify cron + Resend)
📊
Weekly commission reconciliation agent
Every Monday at 9am. Queries partners table for active referral partners. Queries orders from past 7 days with partner_referred=true. Sends Resend email to each partner: "Last week My30A Host sent you N leads using code MY30A. How many converted? Reply to confirm commission." Welson checks replies and marks in admin.html.
Cost: $0 (Netlify cron + Resend)

Partner request flow

When guest taps "Request via Vitoria" for a partner service:

  1. Guest fills form: service type, date, # people, contact info, notes
  2. Netlify Function saves lead to orders table (type='partner_referral', status='sent')
  3. Resend sends email to partner: name, date, contact, service needed, code MY30A
  4. Resend sends confirmation to guest: "I've sent your request to [partner]. Expect contact in 2 hours."
  5. Cron checks 2h later → if order still status='sent' → second email to partner
  6. Cron checks 4h later → if still no response → email alert to dealsconnectllc@gmail.com
  7. Weekly Monday cron → summary email to each partner: "N MY30A leads last week"

Analytics — track everything from day 1

Every user action must be saved in Supabase for future valuation and partner subscription pitches. This data is the company's most valuable asset.

-- 6. ANALYTICS EVENTS — every action tracked
CREATE TABLE analytics_events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_email TEXT, -- null for anonymous visitors
  session_id TEXT NOT NULL, -- track anonymous users too
  event_type TEXT NOT NULL, -- see event types below
  event_data JSONB DEFAULT '{}', -- partner_name, category, value, etc
  property_id UUID REFERENCES properties(id),
  community TEXT, -- Rosemary Beach, WaterColor, etc
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Event types to track:
-- app_open | chat_message | partner_view | partner_click
-- service_started | service_completed | order_paid
-- tip_added | rating_submitted | loyalty_upgraded
